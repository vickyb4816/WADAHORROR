### 1. NARRATIVE ARCHITECTURE & STORYLINE PROGRESSION

The story of *Wada Horror – Tatya Vinchu* unfolds through environmental storytelling, found journal entries, and antique Marathi diaries left by the deceased Inamdar family:

```
[ACT 1: THE ARRIVAL & AWAKENING]
- Laksha enters the Wada compound searching for family heritage records.
- Collects Clue 1 (Found at Entrance Verandah): The Caretaker's Warning note.
- Tatya Vinchu sits dormant in the corner of the Drawing Room in toy form.
- Solving Puzzle 1 (Grandfather Clock) triggers Tatya's awakening stinger chant.

[ACT 2: UNCOVERING THE TANTRIC CURSE]
- Laksha flees into the interior courtyard; finds torn diary pages of Baba Chamatkar.
- Collects Clue 2 & 3: The Tantric Soul Binding Chant ("Om Bhag Bhuge...").
- Collects Sacred Matchbox & Incense in the Kitchen & Store Room.
- Solves Puzzle 2 (Deoghar Puja Room 4-Diya Lighting): Unlocks hidden inner sanctum compartment holding the Heavy Padlock Key.

[ACT 3: THE SECRET RITUAL & TERRACE ESCAPE]
- Tatya stalks Laksha aggressively onto the First Floor and upper gallery.
- Collects Clue 4 & 5: The Inamdar Family Will & The Copper Scorpion Dagger Note.
- Solves Puzzle 3 (3-Digit Padlock Dial on Antique Grain Chest in Store Room).
- Obtains the Purified Camphor / Sacred Bell needed for the final exorcism confrontation.
```

### 4. WADA PUZZLE SYSTEM SPECIFICATIONS

#### PUZZLE 1: Grandfather Clock Pendulum (Drawing Room)
- **Objective**: Laksha inspects the grandfather clock in the drawing room. The clock is frozen.
- **Solution**: Interact with the clock face to rotate minute/hour hands to **12:15** (found in `doc_clock_riddle`).
- **Reward**: The bottom pendulum drawer slides open, rewarding the **Sacred Brass Key (`key_puja_room`)** and triggering Tatya's transition from dormant to active stalking.

#### PUZZLE 2: Deoghar Puja Room 4-Diya Solar Sequence (Puja Room)
- **Objective**: In the pitch-dark Puja room (`room_puja`), 4 brass oil lamps (Diyas) surround the central Ganesh/Kuldaivat idol.
- **Requirement**: Laksha must hold the `item_matchbox` in inventory.
- **Sequence**: Player must light the Diyas in exact cardinal order:
  1. East Diya (`diya_east`)
  2. North Diya (`diya_north`)
  3. West Diya (`diya_west`)
  4. South Diya (`diya_south`)
- **Penalty**: Lighting out of order snuffs out all 4 Diyas with an eerie sigh and alerts Tatya within an 8-meter radius!
- **Reward**: Hidden stone compartment underneath the altar grinds open, revealing the **Master Bedroom 2 Key (`key_bedroom2`)**.

#### PUZZLE 3: Padlock 3-Digit Combination Dial (Store Room Grain Trunk)
- **Objective**: An iron-banded antique wooden chest in the Store Room (`room_store`) is secured with a 3-dial brass rotary lock.
- **Solution**: Set dials to **[ 9 ] - [ 3 ] - [ 6 ]** (derived from `doc_store_chest_code`).
- **Reward**: Chest pops open, providing the **Heavy Padlock Key (`key_terrace_roof`)** and sacred camphor for the endgame.

#### SCRIPT 3: `DocumentViewerUI.gd`
*Attach this script to `res://scenes/ui/DocumentViewerUI.tscn` (Root Control node).*

```gdscript
# File: res://scripts/ui/DocumentViewerUI.gd
extends Control

@onready var title_label_mr: Label = $PaperContainer/MarginContainer/VBoxContainer/TitleMr
@onready var title_label_en: Label = $PaperContainer/MarginContainer/VBoxContainer/TitleEn
@onready var content_text_mr: Label = $PaperContainer/MarginContainer/VBoxContainer/ContentMr
@onready var content_text_en: Label = $PaperContainer/MarginContainer/VBoxContainer/ContentEn
@onready var audio_paper: AudioStreamPlayer = $AudioPaperTurn

var is_open: bool = false

func _ready() -> void:
	visible = false
	if has_node("/root/PuzzleManager"):
		PuzzleManager.document_opened.connect(open_document)
		PuzzleManager.document_closed.connect(close_document)

func _input(event: InputEvent) -> void:
	if is_open:
		if event.is_action_pressed("ui_cancel") or (event is InputEventKey and event.pressed and (event.keycode == KEY_ESCAPE or event.keycode == KEY_E)):
			close_document()

func open_document(doc_id: String) -> void:
	if not has_node("/root/PuzzleManager"):
		return
	
	var data: Dictionary = PuzzleManager.documents_db.get(doc_id, {})
	if data.is_empty():
		return
	
	title_label_mr.text = data.get("title_mr", "")
	title_label_en.text = "(" + data.get("title_en", "") + ")"
	content_text_mr.text = data.get("content_mr", "")
	content_text_en.text = data.get("content_en", "")
	
	is_open = true
	visible = true
	Input.mouse_mode = Input.MOUSE_MODE_VISIBLE
	
	if audio_paper:
		audio_paper.play()

func close_document() -> void:
	if not is_open:
		return
	
	is_open = false
	visible = false
	Input.mouse_mode = Input.MOUSE_MODE_CAPTURED
	if has_node("/root/PuzzleManager"):
		PuzzleManager.emit_signal("document_closed")
```

#### SCRIPT 4: `DiyaAltarPuzzle.gd`
*Attach this script to `res://scenes/interactables/DiyaAltar.tscn` in the Puja Room.*

```gdscript
# File: res://scripts/interactables/DiyaAltarPuzzle.gd
class_name DiyaAltarPuzzle
extends Node3D

signal all_diyas_lit

# 4 Diyas child nodes (each has an OmniLight3D and Flame Mesh)
@export var diya_east_path: NodePath = ^"Diya_East"
@export var diya_north_path: NodePath = ^"Diya_North"
@export var diya_west_path: NodePath = ^"Diya_West"
@export var diya_south_path: NodePath = ^"Diya_South"

@export var reward_key_item_path: NodePath = ^"SecretCompartment/RewardKey"
@onready var compartment_anim: AnimationPlayer = $CompartmentAnimationPlayer

# Expected Cardinal Solar Order: East (1), North (2), West (3), South (4)
var required_order: Array[String] = ["east", "north", "west", "south"]
var current_step_index: int = 0
var is_solved: bool = false

var diya_nodes: Dictionary = {}

func _ready() -> void:
	diya_nodes["east"] = get_node_or_null(diya_east_path)
	diya_nodes["north"] = get_node_or_null(diya_north_path)
	diya_nodes["west"] = get_node_or_null(diya_west_path)
	diya_nodes["south"] = get_node_or_null(diya_south_path)
	
	extinguish_all_diyas(false)

# Called by player interaction on individual diya sub-nodes
func light_diya(diya_direction: String) -> void:
	if is_solved:
		return
	
	# Verify player has matches in inventory
	if has_node("/root/InventoryManager"):
		if not get_node("/root/InventoryManager").has_item("item_matchbox"):
			get_node("/root/InventoryManager").emit_signal("interaction_message", "Need matches to light the Diya.")
			return
	
	print("[PUZZLE] Lit diya: ", diya_direction)
	set_diya_flame_active(diya_direction, true)
	
	# Verify correctness in sequence
	if diya_direction == required_order[current_step_index]:
		current_step_index += 1
		if current_step_index >= required_order.size():
			solve_puzzle()
	else:
		# Sequence failed! Snuff all flames and alert Tatya
		trigger_failure_penalty()

func set_diya_flame_active(dir: String, active: bool) -> void:
	var node = diya_nodes.get(dir)
	if node:
		if node.has_node("OmniLight3D"):
			node.get_node("OmniLight3D").visible = active
		if node.has_node("FlameMesh"):
			node.get_node("FlameMesh").visible = active

func extinguish_all_diyas(play_sound: bool = true) -> void:
	for dir in diya_nodes.keys():
		set_diya_flame_active(dir, false)
	current_step_index = 0
	
	if play_sound and has_node("/root/InventoryManager"):
		get_node("/root/InventoryManager").emit_signal("interaction_message", "A cold gust blew out the flames! Order was incorrect.")

func trigger_failure_penalty() -> void:
	extinguish_all_diyas(true)
	
	# Alert Tatya AI to the Puja room noise
	var enemies = get_tree().get_nodes_in_group("enemy")
	for enemy in enemies:
		if enemy.has_method("hear_noise"):
			enemy.hear_noise(global_position, 14.0)

func solve_puzzle() -> void:
	is_solved = true
	print("[PUZZLE] Deoghar Diya Sequence Solved!")
	
	if has_node("/root/PuzzleManager"):
		PuzzleManager.mark_puzzle_solved("diya_altar_solved")
	
	if compartment_anim and compartment_anim.has_animation("slide_open"):
		compartment_anim.play("slide_open")
	
	if has_node("/root/InventoryManager"):
		get_node("/root/InventoryManager").emit_signal("interaction_message", "The altar shrine shifted open!")
```

# File: res://scripts/interactables/DialLockPuzzle.gd
class_name DialLockPuzzle
extends Node3D

@export var target_code: Array[int] = [9, 3, 6]
@export var chest_lid_pivot_path: NodePath = ^"ChestLidPivot"
@export var reward_item_id: String = "key_terrace_roof"

var current_dial_values: Array[int] = [0, 0, 0]
var is_unlocked: bool = false

# Called by DialLockUI when digits change
func set_digit(dial_index: int, value: int) -> void:
	if is_unlocked or dial_index < 0 or dial_index >= 3:
		return
	current_dial_values[dial_index] = value % 10
	check_code()

func check_code() -> void:
	if is_unlocked:
		return
	
	if current_dial_values == target_code:
		unlock_chest()

func unlock_chest() -> void:
	is_unlocked = true
	print("[PUZZLE] Store Room Padlock Opened!")
	
	if has_node("/root/PuzzleManager"):
		PuzzleManager.mark_puzzle_solved("store_dial_solved")
	
	# Open chest lid smoothly
	if chest_lid:
		var tween = create_tween()
		tween.tween_property(chest_lid, "rotation_degrees:x", -85.0, 1.2)
	
	# Award key to player
	if has_node("/root/InventoryManager"):
		var key_data: Dictionary = {
			"id": reward_item_id,
			"name": "Heavy Padlock Key",
			"description": "A heavy iron padlock key found inside the grain chest. Unlocks the First Floor Terrace & Roof Gate.",
			"icon": "res://assets/icons/key_terrace.png",
			"category": "key"
		}
		get_node("/root/InventoryManager").add_item(key_data)

### 8. LOW-SPEC GT 730 & i3-4150 OPTIMIZATION GUIDE

- **Pure 2D Canvas Layer Text**: Documents render via Godot's built-in 2D font rasterizer, requiring **zero extra draw calls or sub-viewports**.
- **Static Light Toggles**: The 4 Diyas use unshadowed `OmniLight3D` nodes with ranges capped at `3.0m`, meaning lighting them introduces no GPU fill-rate penalty.
- **Physics Freeze during Inspection**: When reading documents or dialing the padlock, Laksha's 3D physics updates are paused, keeping the CPU frame time at **< 0.05ms**.
