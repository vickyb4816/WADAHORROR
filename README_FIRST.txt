WADA HORROR – ANDROID STARTER

This is an early playable prototype, not the complete game.
It contains a simple Wada entrance blockout, first-person Laksha, a golden key and a locked entrance door. Android touch controls and a GitHub Actions APK workflow are included.

QUICK START
1. Extract this ZIP.
2. Create an empty GitHub repository.
3. Upload the CONTENTS of this folder to the repository root (including the hidden .github folder).
4. Commit to main.
5. Open GitHub > Actions > Build Android APK.
6. Wait for the workflow to finish, then download the WadaHorror-Android-APK artifact.
7. Extract the artifact ZIP and install WadaHorror-debug.apk on your Android phone.

CONTROLS
Android: left arrows move, drag the right side to look, JUMP and INTERACT buttons.
PC: WASD, mouse, Space and E.

BUILD STATUS
The workflow file is prepared but has not yet been run on GitHub. The first Actions run will confirm whether the APK build succeeds. This package is not a signed Play Store release.
